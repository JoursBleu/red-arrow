Quick Start

快速开始

  1. Install安装
    Download the Windows installer or Android APK from GitHub Releases 从 GitHub Releases 下载 Windows 安装器或 Android APK
  2. Configure配置
    Enter your SSH host, port, user, and key; ProxyJump is optional 填写 SSH 地址、端口、用户和密钥；ProxyJump 可留空
  3. Connect连接
    Connect, then choose local-only, global, or mainland-China-bypass mode on Windows 连接后，Windows 可选择仅本地、全局或绕过中国大陆模式
  4. Use使用
    Windows configures WinINET automatically; Android can share its proxy over the LAN Windows 自动配置 WinINET；Android 可将代理共享给局域网设备
